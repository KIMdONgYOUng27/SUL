# SUL · 사이 인터뷰 노트

한국을 관광하는 외국인과 대면 인터뷰를 진행하며 질문과 답변을 기록하는 도구입니다.

**웹페이지:** https://kimdongyoung27.github.io/SUL/

시작과 여행 이야기, 택시, 번역, 현금·환전, 쓰레기 처리, 마무리로 구성됩니다. 경험 상태에 따라 후속 질문이 달라지며, 주제를 자유롭게 이동할 수 있습니다. 예상 밖 이야기는 여러 주제를 연결해 별도로 기록할 수 있습니다.

## 질문 편집

웹페이지 상단 **질문 편집**에서 별도 편집 화면을 엽니다. 주제별 한국어·영문 질문, 인터뷰 진행 안내, 추가 질문, 주제 사이 연결 문장을 수정할 수 있습니다. **이 브라우저에 적용**을 누르면 같은 브라우저의 인터뷰 화면에 반영됩니다. 편집 중인 내용은 별도 임시 저장되며, 기존 인터뷰 답변은 삭제되지 않습니다. 새로 기록한 답변에는 당시 질문 문구가 함께 저장됩니다.

질문 설정은 인터뷰 응답과 별도입니다. **질문 파일 내려받기**로 `questions.json`을 저장하고 다른 브라우저의 편집 페이지에서 가져올 수 있습니다. 모든 사용자에게 공통 기본값을 적용하려면 이 파일을 저장소 루트의 `questions.json`으로 커밋하면 됩니다. 브라우저별 설정이 있으면 그 설정이 우선합니다. 웹 편집 화면에서 변경한 내용이 GitHub에 자동으로 업로드되지는 않습니다.

## 저장과 백업

기록은 현재 브라우저의 localStorage에 저장됩니다. 서버 전송이나 기기 간 자동 동기화는 없습니다. 인터뷰 후 **전체 백업**을 내려받으세요. 다른 기기에서는 **백업 파일 가져오기**로 복원할 수 있습니다. 동일한 인터뷰 ID가 이미 있으면 기존 기록을 유지합니다.

참여자별 텍스트·JSON과 전체 CSV 내보내기를 지원합니다. 직접 발언과 인터뷰어 해석은 별도로 기록합니다. 영문 질문도 표시할 수 있습니다.

설치 없이 사용하려면 `인터뷰-챗봇.html`을 내려받아 브라우저로 여세요. 웹페이지와 내려받은 파일의 저장 공간은 별개입니다. 옮길 때는 백업 파일을 사용하세요.

## 소스와 확인

- `index.html`: 화면 진입점
- `interview-model.js`: 질문, 분기, 백업 검증
- `interview.js`: 기록·저장·내보내기
- `interview.css`: 반응형 화면
- `tests/interview.test.js`: 질문 분기와 데이터 형식 테스트

Node.js가 있는 환경에서 `npm test`로 확인합니다. GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다. 공개 소스에는 인터뷰 응답이나 인증 정보가 포함되지 않습니다.
